# Reference

Exact facts to look up: syntax, values, catalogs.

For everyone:

- [Keyboard shortcuts](/docs/reference/keyboard-shortcuts): every shortcut in the app.
- [Automation nodes](/docs/reference/automation-nodes): every trigger and step an automation can use, with its settings.
- [Assistant tools](/docs/reference/chat-agent-tools): what the AI assistant can do, which tools write, and the permission each needs.

- [Test layers](/docs/reference/test-layers): the four kinds of test, where each lives and the command that runs it.
- [Tech stack](/docs/reference/tech-stack): the frameworks, services and versions Monark is built on.

For operators:

- [Environment variables](/docs/reference/environment-variables): every variable each service reads, and its default.
- [CI jobs](/docs/reference/ci-jobs): every GitHub Actions job, when it runs and what fails it.
