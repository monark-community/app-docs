# Delivery history

`/admin/webhooks/<id>/deliveries`. A paged list of every delivery attempted for this endpoint. Each row shows :

- The event type.
- Status : **Delivered** (green), **Pending** (amber), **Failed** (red).
- Attempt count.
- Last error (if any).
- Timestamp.
