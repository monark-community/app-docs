# Organization

Settings that apply to your whole organization: how it looks, the files it stores, the badges people earn, and the record of what admins changed.

Admins only. If you hold the Administrator role, **Admin** appears at the bottom of the navigation rail (in the menu on a phone); these pages start there.

- [Change your organization's settings](/docs/administer/organization/change-your-organizations-settings): set the name, logo and brand color everyone sees.
- [Manage files](/docs/administer/organization/manage-files): find, download or delete uploaded files, and set up storage buckets.
- [Set up achievements](/docs/administer/organization/set-up-achievements): define the badges people earn and what earns them.
- [Keep an audit trail of admin changes](/docs/administer/organization/keep-an-audit-trail-of-admin-changes): send role, user and settings changes to a logging tool.
