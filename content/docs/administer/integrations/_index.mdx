# Integrations

Connect Monark to the other systems your organization uses: store the credentials automations need, link outside services, send events out, and give scripts their own identity for the API.

Admins only. If you hold the Administrator role, **Admin** appears at the bottom of the navigation rail (in the menu on a phone); these pages start there.

- [Store a secret](/docs/administer/integrations/store-a-secret): keep an external token or API key where automations can use it but no one can read it.
- [Connect GitHub, Telegram, X or Discord](/docs/administer/integrations/connect-github-telegram-x-or-discord): link a service your automations trigger on or act through.
- [Send events to a webhook](/docs/administer/integrations/webhooks): have Monark notify another system whenever something happens.
- [Check webhook deliveries](/docs/administer/integrations/check-webhook-deliveries): see what was sent, find out why a delivery failed, and send it again.
- [Create a service account](/docs/administer/integrations/create-a-service-account): give a script or integration its own API keys and roles.
